# Link Guard logo

The Link Guard mark is a shield holding two interlocking chain links: links, guarded.

## Files

| File | Use |
| --- | --- |
| `link-guard-mark.svg` | the mark on light or mid-tone backgrounds; favicon, avatar, add-on icon |
| `link-guard-mark-dark.svg` | the mark on dark backgrounds |
| `link-guard-mark-mono.svg` | single colour (`currentColor`), links cut out; for coloured backgrounds, print, or theme-aware icons |
| `link-guard-logo.svg` | mark and name side by side, for light backgrounds |
| `link-guard-logo-dark.svg` | mark and name side by side, for dark backgrounds |
| `favicon.ico` | 16, 32 and 48 px |
| `png/` | the mark at 16 to 512 px, and both logos at 128 px height |

The name in the two logo files is live text in a system font stack (Inter, Segoe UI,
system UI, Helvetica Neue, Arial). It renders slightly differently depending on the
fonts available; the PNG files use Inter. For print, or where a pixel-exact wordmark
matters, convert the text to outlines in a vector editor.

## Colours

| Colour | Hex | Where |
| --- | --- | --- |
| Link Guard blue | `#27538e` | shield on light backgrounds; same as the Settings accent |
| Light blue | `#4277c2` | shield on dark backgrounds (3:1 contrast or more against `#151a22`) |
| White | `#ffffff` | chain links |
| Ink | `#182334` | name on light backgrounds |
| Paper | `#f0f4f8` | name on dark backgrounds |

## Using the logo

- **Clear space:** keep free space around the mark of at least a quarter of its height.
- **Minimum size:** the mark is legible from 16 px; use the logo with name from 24 px
  height.
- **Backgrounds:** use the standard mark on white and light greys, the dark variant on
  dark backgrounds, and the monochrome mark in white on Link Guard blue or other strong
  colours.
- **Do not** recolour the shield outside these colours, stretch or rotate the mark,
  add effects such as shadows or gradients, or place the standard mark on busy images.
