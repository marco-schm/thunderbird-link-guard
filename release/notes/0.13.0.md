## Link Guard 0.13.0

This release closes several ways a message could slip a link past Link Guard,
adds two warnings and makes large lists practical.

Security fixes: a link's destination is now decided from the URL Thunderbird
actually opens. A message with a `<base href>` could turn an empty `href` or a
bare `#fragment` into an unchecked web link; relative links now resolve against
the base as well. MathML links and links inside shadow trees are now inspected
and disabled until approved, and HTML `<link>` elements are hidden. The labels
next to links are protected against message CSS in the same way as the panel.
Link text that names a bare domain such as `example.org` is now compared with
the real destination.

New warnings: code or HTML in a link, the shape of a reflected XSS attack on
the linked site, and links that carry another destination, such as an
open redirect, Microsoft Safe Links or Proofpoint URL Defense, when that
destination is off-site and not approved. A link with code in it can only be
allowed for the current message. The "Unusual port" warning has been removed;
a link with an explicit port follows the approval of its host.

The notice shows warnings in red with a warning triangle. A blocked host now
offers only **Unblock**, behind a confirmation, and a block wins over every
approval. A new setting hides the destination label next to links for messages
whose layout it disturbs; it is on by default.

Imported lists may now hold 5,000 entries and 512 KiB each, still at most 20
lists. Host checks, lookalike detection and the background state were rebuilt
so that full lists do not slow down message display, and lookalikes of every
trusted domain are now detected, not only of the first 10,000.

The project has a logo and full user and developer documentation in `docs/`.

The permissions remain `messagesRead`, `scripting`, and `storage`. Thunderbird
151 or newer is required. The new interface texts in the 19 non-English
languages have not been reviewed by native speakers. See the [security policy](https://github.com/marco-schm/thunderbird-link-guard/blob/v0.13.0/SECURITY.md)
for limitations. The XPI and `SHA256SUMS` are built only after the YubiKey-signed
tag passes verification.
