## Link Guard 0.14.2

A packaging release for the Thunderbird add-on review. Link Guard behaves exactly as
in 0.14.1.

Link Guard now also requests the `messagesModify` permission. Thunderbird's add-on
review requires it for message display scripts, which Link Guard uses to turn off the
links in a displayed message and show its notice. When Thunderbird updates Link Guard,
it asks once to confirm the new permission. Link Guard still has no host permissions
and no network access, except the list sources you add yourself.

The XPI no longer contains `vendor/MPL-2.0.txt`. The bundled Public Suffix List keeps
its MPL 2.0 notice and licence link in its own header, and the full licence text stays
in the repository.

The permissions are `messagesModify`, `messagesRead`, `scripting`, and `storage`.
Thunderbird 151 or newer is required. See the [security policy](https://github.com/marco-schm/thunderbird-link-guard/blob/v0.14.2/SECURITY.md)
for limitations. The XPI and `SHA256SUMS` are built only after the YubiKey-signed tag
passes verification.
