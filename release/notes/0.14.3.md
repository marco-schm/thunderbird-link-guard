## Link Guard 0.14.3

A translation release for the Thunderbird add-on review. Link Guard behaves exactly as
in 0.14.2.

Several Spanish, French, Italian and Brazilian Portuguese strings were machine
translations that missed the meaning. The button that stages an imported list as a
disabled list read as a list of injured or disabled people in some languages, and
"Stage update" turned into an update of a stage or a theatre stage. These and other
inaccurate strings are corrected, the add-on name stays "Link Guard" in every language,
and the Spanish strings now address the user consistently. One Danish button label is
clearer.

The permissions are `messagesModify`, `messagesRead`, `scripting`, and `storage`.
Thunderbird 151 or newer is required. See the [security policy](https://github.com/marco-schm/thunderbird-link-guard/blob/v0.14.3/SECURITY.md)
for limitations. The XPI and `SHA256SUMS` are built only after the YubiKey-signed tag
passes verification.
