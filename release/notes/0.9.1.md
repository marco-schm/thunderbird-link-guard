## Link Guard 0.9.1

Link Guard now has ten complete interface languages: English, German, Spanish,
French, Brazilian Portuguese, Italian, Polish, Russian, Japanese, and
Simplified Chinese. It follows Thunderbird's interface language and uses
English when that language is not available, even if Thunderbird has a different
secondary language installed. Security warnings and approval controls are
localized as well.

The link approval policy and permissions are unchanged. Thunderbird 151 or
newer is required. Download `link-guard-0.9.1.xpi` below and install it through
**Add-ons and Themes** → **Install Add-on From File**. Review the requested
`messagesRead`, `scripting`, and `storage` permissions.

Link Guard cannot authenticate a sender or inspect a browser's final redirect
destination. See the [security policy](https://github.com/marco-schm/thunderbird-link-guard/blob/v0.9.1/SECURITY.md)
for details. The XPI and `SHA256SUMS` are built only after the YubiKey-signed
tag passes verification.
