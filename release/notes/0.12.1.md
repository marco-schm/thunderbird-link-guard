## Link Guard 0.12.1

A small layout fix for Settings. The text boxes of the rule cards now line up
within each row, even when one card's description is longer, and the fields of
a warning rule (label, target, pattern and the remove button) share one height.
There are no functional changes compared with 0.12.0.

The permissions remain `messagesRead`, `scripting`, and `storage`. Thunderbird
151 or newer is required. See the [security policy](https://github.com/marco-schm/thunderbird-link-guard/blob/v0.12.1/SECURITY.md)
for limitations. The XPI and `SHA256SUMS` are built only after the YubiKey-signed
tag passes verification.
