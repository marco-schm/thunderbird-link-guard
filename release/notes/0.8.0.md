## Link Guard 0.8.0

This is the first regular GitHub release. It uses the same link policy and
permissions as 0.7.3; the release process now publishes reviewed notes and
still requires a YubiKey-signed tag.

### Install

Download `link-guard-0.8.0.xpi` below. In Thunderbird, open **Add-ons and
Themes** → **Install Add-on From File**, select the XPI, and review its
permissions. Thunderbird 151 or newer is required. The extension requests
`messagesRead`, `scripting`, and `storage`, with no blanket host permission.

### Behavior and limits

- Web links in displayed mail stay inactive until their exact host or an
  explicitly chosen domain scope is approved. Temporary approvals last only
  for the current message.
- Lookalike domains, HTTP links, misleading visible URLs, and public shorteners
  receive additional warnings. No default trusted-host list is included.
- Link Guard cannot authenticate a sender, inspect a browser's final redirect
  destination, or protect QR codes and attachments. Review the [security
  policy](https://github.com/marco-schm/thunderbird-link-guard/blob/v0.8.0/SECURITY.md)
  before relying on it for sensitive mail.

The runtime was tested manually in Thunderbird 159 on macOS, including an
OpenPGP message, a restored message after restart, a remote-list preview, and
German and English UI. Other Thunderbird versions and operating systems have
not been tested live. The release XPI and `SHA256SUMS` are built by GitHub
Actions only after the YubiKey tag signature passes verification.
