## Link Guard 0.10.1

When you block a host in a message, Link Guard now asks whether to block that
host alone or its whole registrable domain. Existing exact-host blocks remain
exact. Whole-domain approval and block rules are shown as `*.example.com` in
Settings. In Link Guard, that notation includes `example.com` itself and all
subdomains. Imported JSON lists still contain exact hosts only.

Whole-domain blocks take priority over saved and imported approvals. Explicit
temporary approval remains limited to the current message. Broad approvals
still exclude selected shared-content hosts. All ten interface languages have
the new scope prompt and rule explanations.

The permissions remain `messagesRead`, `scripting`, and `storage`. Thunderbird
151 or newer is required. See the [security policy](https://github.com/marco-schm/thunderbird-link-guard/blob/v0.10.1/SECURITY.md)
for limitations. The XPI and `SHA256SUMS` are built only after the YubiKey-signed
tag passes verification.
