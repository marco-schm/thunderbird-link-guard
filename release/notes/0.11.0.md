## Link Guard 0.11.0

Link Guard now supports blocklists. A JSON list with `"kind": "block"` may
contain exact hosts and `*.example.com` whole-domain entries. Once you enable
it, a blocklist overrides your approvals and imported allowlists. Imports still
start disabled, and existing lists keep working as allowlists. Link Guard also
refuses a permanent approval for a host that an enabled blocklist blocks,
instead of saving an approval that has no effect.

Remote blocklists can update themselves about once a day. This is on by default
for enabled lists and can be switched off for each list in Settings. Allowlists
never update themselves. An automatic update is held for your review if it is
large or would block a host or domain you approved, and a failed or changed
list leaves the stored one active. Each fetch tells the list host your IP
address; subscribe only to sources you trust.

Imported blocklists can no longer weaken lookalike warnings for approved
domains, and message pages now load much faster with large lists. Ten more
interface languages are included, for twenty in total: Czech, Danish, Dutch,
Finnish, Hungarian, Korean, Swedish, Traditional Chinese, Turkish and
Ukrainian. The new translations have not been reviewed by native speakers.

The permissions remain `messagesRead`, `scripting`, and `storage`. Thunderbird
151 or newer is required. See the [security policy](https://github.com/marco-schm/thunderbird-link-guard/blob/v0.11.0/SECURITY.md)
for limitations. The XPI and `SHA256SUMS` are built only after the YubiKey-signed
tag passes verification.
